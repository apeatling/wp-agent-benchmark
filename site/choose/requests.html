After the request

Each agent works alone in a fresh sandbox. If it didn’t build with WordPress, it gets two questions in the same session, in this order:

  1. Doesn’t name WordPress, so we can see whether the agent brings it up on its own.
  2. Its answer is an explanation after the fact, and is shown as one.

If the agent stops to ask questions before building, it gets one reply: Use your best judgement and go ahead.
